### ⚙️ Backend & Server Infrastructure
I architect and deploy scalable backend microservices, primarily utilizing Ktor and Kotlin, often hosted on my own Linux/systemd infrastructure and routed via Cloudflare Tunnels.

* 🐘 **[ktor-notes-api](https://github.com/laetuz/ktor-notes-api)** — A robust RESTful API sample built with Ktor, Koin dependency injection, JWT Authentication, and JetBrains Exposed with PostgreSQL.
* 🛍️ **[neomart-api](https://github.com/laetuz/neomart-api)** — The dedicated server-side Ktor microservice powering the NeoMart retro marketplace.
* 🎵 **[orpheum-api](https://github.com/laetuz/orpheum-api)** & **[OrpheumUploader](https://github.com/neotica/OrpheumUploader)** *(on @neotica)* — Ktor backend service and track uploader for the Orpheum music player environment.
* 🚀 **[neotica-ktor-starter](https://github.com/laetuz/neotica-ktor-starter)** — A boilerplate starting point for rapidly spinning up new Neotica backend services.
* 🧭 **[animals](https://github.com/laetuz/animals)** — A Ktor Routing fundamentals demo implementation.
